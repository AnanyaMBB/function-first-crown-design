Research plan · November 2026

THE METHOD

Define, fill, guarantee

Function-first reverses the usual order. The rules define what the crown must do; the learned model only decides how it looks.

1 · RULES

Define

Derive what the crown must do from the patient’s scans and jaw movement: contacts, clearance, load axis, table width.

Output: a skeleton of points, paths and forbidden regions.

2 · LEARNED

Fill

Find the most natural tooth that meets the skeleton. Function is the goal; the learned prior keeps it plausible.

Output: several candidate crowns.

3 · RULES

Guarantee

SDF operations make fit, minimum thickness, bur radius and no interferences true by construction, as LEAP 71 does.

Output: crowns that pass every hard rule, then ranked by simulated wear and lifetime.

SHAPE SEARCH · TEST 1

Shape space: one model or one per tooth type

OPTION A · DEEPSDF

One model, all teeth

  • Tooth type is an input to one decoder
  • Codes pulled to their type’s mean
  • Shares what all teeth have in common

OPTION B · DEEPSDF

A model per tooth type

  • A decoder and code space per type
  • All capacity on one shape family
  • 14 models, fewer teeth to train each

SAME TEST FOR BOTH

Fit held-out real teeth

  • F-score at 0.1, 0.2 and 0.3 mm
  • Normal consistency and curvature
  • Technician review of fissures
  • Codes stay within their type

Go / no-go: if fissures vanish in the held-out fit, generation will lose them too.

SHAPE SEARCH · TEST 2

Generator: latent search or diffusion

OPTION A

Latent search

  • Start at the type mean or the arch model’s guess
  • Gradient steps on code and pose
  • Vary: start, number of starts, prior weight

OPTION B

Diffusion model

  • Transformer over per-tooth codes and poses
  • Each step corrected by the point tests
  • Vary: requirements as input, steps corrected

SAME MEASURES FOR BOTH

Score every candidate

  • Function: contact error, clearance, load angle
  • Stage 3 change by region (mm)
  • Natural look and variety
  • Time and correction budget

Choose: the smaller Stage 3 change at equal look, or diffusion to start and search to finish.

THE PLAN

Order of experiments

1

Licence check

Read the Teeth3DS+ licence before any training.

Gate: training allowed, or run it with an academic partner

2

Analytic baseline

An FDI 16 crown built from SDF primitives and passed through Stage 3. No training.

Outcome: the bar the learned fill must beat

3

Shape space

DeepSDF for all teeth against one per type, on FDI 16/26; held-out fit test.

Gate: fissures survive the fit

4

Latent search

Simulated cases with average jaw values first.

Gate: requirements met with a small Stage 3 change

5

Diffusion against search

The same cases and measures as step 4.

Outcome: choose the generator, or combine them

6

Patient jaw motion, then implants

CBCT-based kinematics checked against jaw tracking; then implant crowns with the implant axis.

Gate: paths within tolerance, safety distances met

Every result is also compared with the fallback order: the prior proposes, the rules correct.
